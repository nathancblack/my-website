I study computer science at the University of Delaware. I work on machine learning, parallel computing, and input systems. My interest is in how low-level signals — sensor readings, key actuation depth, tabular event records — can be turned into useful higher-level behavior.

Research interests

  • Applied machine learning on tabular and event data
  • Parallel and high-performance computing (CUDA, MPI)
  • Human input systems and device drivers

Selected work

  1. An analog input driver for Hall-effect keyboards. Maps per-key actuation depth on a QwertyKeys Neo65 Sonic HE+ to continuous gamepad axes, allowing a standard keyboard to function as an analog input device. 2026. [code]
  2. Multi-class classification of severe weather events. Compares XGBoost and TabNet on contextual tabular features from the NOAA Storm Events Database, 2023–2024. Gradient-boosted trees outperform the deep tabular model on this task. 2026. [code]
  3. k-means clustering from first principles. A from-scratch NumPy implementation written for machine learning coursework, covering initialization, assignment, and convergence. 2026. [code]
  4. UDelaWhere: location inference as a game. A campus-scale geographic guessing game built with a team of four in 36 hours at HenHacks 2025. [code]

Machine learning, parallel computing, statistics. Additional implementation work in Bayesian classification and spam detection.
